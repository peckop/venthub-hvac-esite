Görevin: Palette ajanını GitHub CLI üzerinden ateşle ve işlemi otonoma devret.

## 🚀 Gece Vardiyası Tetikleme: PALETTE 🎨

```bash
gh workflow run jules-a11y.yml
```

**Operasyon Özeti:** 
Bu komut GitHub Actions altyapısını uyarır. Palette uyanacak, arayüzdeki ARIA etiketlerini, kontrast sorunlarını ve mikro etkileşim (UX) eksikliklerini düzeltecek bir Pull Request açacaktır.
İşlemin seyrini projenin GitHub **Actions** sekmesinden izleyebilirsin.

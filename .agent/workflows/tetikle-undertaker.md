Görevin: Undertaker ajanını GitHub CLI üzerinden ateşle ve işlemi otonoma devret.

## 🚀 Gece Vardiyası Tetikleme: UNDERTAKER ⚰️

```bash
gh workflow run jules-undertaker.yml
```

**Operasyon Özeti:** 
Bu komut GitHub Actions altyapısını uyarır. Undertaker uyanacak, kullanılmayan export'ları, hayalet import'ları ve atıl kalan dosyaları bulup projeden temizleyen bir Pull Request açacaktır.
İşlemin seyrini projenin GitHub **Actions** sekmesinden izleyebilirsin.

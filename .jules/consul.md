## 2025-02-28 - Localize Vortice and CTAs
**Learning:** Some strings, like `categoryName` passed dynamically to the `{t()}` hook need interpolation variables passed correctly. Moreover, when extracting HTML strings that contain formatting (like `<strong>`), `dangerouslySetInnerHTML` combined with stripping the tags from `tr.ts` or passing tags as parameters needs to be used to maintain security and layout integrity.
**Action:** When adding keys for strings containing simple styling (e.g. `<strong>Compasso d'Oro</strong>`), remove the tags in the i18n file and either re-apply them in the component or use `dangerouslySetInnerHTML`. Interpolate variables directly in the i18n `t` hook call.

# 015 - Tasarım Sistemi Otoritesi

## 🎯 Hedef
Page Builder içinde kullanılacak olan tüm görsel blokların (grafikler, tablolar, dB göstergeleri) merkezi bir tasarım sistemine (Design System) bağlanması.

## ✅ Alt Görevler
- [ ] Otorite blokları için bileşen kütüphanesini (Atom/Molekül) kur.
- [ ] Renk ve spacing (boşluk) standartlarını JSONB verisiyle uyumlu hale getir.
- [ ] Tüm blokların "Dark/Light Mode" ve "Responsive" uyumunu mühürle.

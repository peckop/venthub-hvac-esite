# 017 - Görsel Sayfa Oluşturucu (Visual Page Builder)

## 🎯 Hedef
Admin kullanıcının hiçbir kod yazmadan, veritabanından beslenen dinamik bileşenlerle kategori sayfalarını baştan sona kurgulayabildiği görsel arayüzü teslim etmek.

## ✅ Alt Görevler
- [ ] **Arayüz Tasarımı:** Sürükle-bırak veya blok-bazlı sayfa düzenleme panelini oluştur.
- [ ] **Bileşen Kütüphanesi:** Teknik tablolar, dB grafikleri ve hero alanları için hazır "Otorite Blokları" ekle.
- [ ] **Kalıcı Kayıt:** Tasarlanan sayfaların JSON şemasını `categories.authority_content` alanına mühürle.
- [ ] **Görsel Doğrulama:** Oluşturulan sayfaların responsive ve SEO uyumluluğunu test et.

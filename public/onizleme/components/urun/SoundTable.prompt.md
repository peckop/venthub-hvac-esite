Sessiz fan serilerinde modellerin ses değerlerini hız kademeleriyle karşılaştırır.

```jsx
<SoundTable kip="teklif" metin={sozluk} modeller={[
  { sku: 'VRT-17160', ad: 'Lineo 100 Quiet', foto: url, hizlar: [{ ad: '1. hız', db: 21.2 }, { ad: '2. hız', db: 24.0 }, { ad: '3. hız', db: 26.1 }] },
]} />
```

- Değer katalogdaki gibi (ses basıncı, emiş, 3 m); altta `ds.ses-deger-notu`.
- Mekân sınırı, "C sınıfı", onay işareti yok (iptal, Recep 10-24).

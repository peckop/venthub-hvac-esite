
Sayfanın işini bitiren tek eylem için dolu kiremit düğme; bir sayfada birden fazla kullanılamaz (K5).

```jsx
<AnaEylemDugmesi onClick={teklifIste}>Bu model için teklif iste</AnaEylemDugmesi>
```

- İkinci bir eylem gerekiyorsa o eylem `CerceveliDugme` olur — kiremit çoğaltılmaz.
- Gövde paragrafı içindeki üçüncül eylem turkuaz metin bağlantısıdır; eylem asla ince metin bağlantısı değildir.
- `tamGenislik` yalnız mobil alt panelde kullanılır.
- Hover/press durumu ÖLÇÜLMEDİ (kaynak çizimlerde 0 eşleşme) — bilinçli olarak tanımlanmadı.

# Skill gözlemleri — `task-observer` defteri

Skill'lerin iş sırasında yakalanan sürtünmeleri: Recep düzeltmeleri, tekrarlayan akışlar,
çiğnenen kurallar, daha iyi yollar. Biçim ve protokol: `.claude/skills/task-observer/SKILL.md`.

- `acik/` — karar bekleyen gözlemler (bir dosya = bir gözlem, frontmatter zorunlu).
- `arsiv/` — kabul/red/uygulandı olarak karara bağlananlar (silinmez).
- `son-inceleme.txt` — son haftalık incelemenin tarihi; `hic` = hiç yapılmadı.

Haftalık inceleme OPS-AUDIT gün kapanışının parçasıdır. CLAUDE.md'ye girecek kural Recep
onayı (REC-*) ister. Repo public: gözlemlerde müşteri/iş verisi olmaz.
